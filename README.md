## 以后如何更新

- 修改个人网站内容：编辑本仓库的 `index.html`，同步修改对应中英文段落。
- 修改网站样式：编辑 `style.css`。
- 修改语言切换：编辑 `script.js`。
- 将修改提交到 `main` 后，GitHub Pages 会自动发布。可在 [Actions](https://github.com/zhangtt19/zhangtt19.github.io/actions) 查看发布结果。
- 更新账号主页介绍：编辑 `zhangtt19/zhangtt19` 仓库中的 `README.md`。
